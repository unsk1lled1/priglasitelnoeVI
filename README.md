# Всемирная история — интерактивное приглашение

Готовый одностраничный сайт на HTML, CSS и JavaScript. Зависимости не нужны; для сервера и сборки используется Node.js 18+.

## Запуск

```sh
npm run dev
```

Откройте http://127.0.0.1:5173. Также можно открыть `index.html` напрямую; локальный сервер рекомендуется для корректной работы видео и буфера обмена.

## Персонализация

В `invitation.config.js` укажите имя второго участника, дату, время и ссылку Google Meet. Эти значения увидят все посетители после загрузки обновлённого сайта. Пустые поля сохраняют плейсхолдеры из задания.

Поля можно менять прямо в письме. Такие изменения сохраняются **только в текущем браузере** и не меняют приглашение для других посетителей. После обновления конфигурации используются новые исходные значения.

## Сборка и размещение

```sh
npm run build
npm run preview
```

Загрузите содержимое `dist/` на любой статический хостинг. Сайт использует относительные пути и работает в подпапке. `npm run preview` доступен по тому же адресу; сначала остановите dev-сервер, если он запущен.

## Структура

- `index.html` — разметка и письмо-приглашение.
- `styles.css` — оформление приглашения и письма.
- `intro.css` — полноэкранная сцена, PNG-перо, свечение и адаптивность вступления.
- `app.js` — переходы, модальное письмо, поля и Google Meet.
- `invitation.config.js` — редактируемые данные приглашения.
- `backg/startBezPera.png`, `backg/pero.png`, `backg/fon.mp4`, `backg/end.png` — оригинальные файлы без изменений.
- `scripts/` — локальный HTTP-сервер с поддержкой видеодиапазонов и сборка.

## Поведение

Стартовая сцена, видео и финальный фон занимают весь viewport без рамок и полей. Отдельное PNG-перо медленно левитирует над компасом. Свечение и клик срабатывают по непрозрачным пикселям пера. Подсказка под ним — обычный текст. Enter/Пробел на перe также запускают видео.

Первый отрисованный кадр видео заменяет сцену за 160 мс, без экрана загрузки. Во время видео интерфейс скрыт. По завершении end.png плавно появляется во весь экран за 700 мс; затем появляются прежние тексты, баннеры и кнопка приглашения. Кнопка открывает письмо; Escape, крестик и нажатие вне письма закрывают его. Сохранены повторный запуск, обработка ошибки видео, проверка ссылки Meet и копирование с запасным вариантом при запрете буфера обмена.

При включённом системном уменьшении движения отключены левитация, пульсация и CSS-переходы; видео по-прежнему запускается только по запросу пользователя. Шрифты Cormorant Garamond и Manrope загружаются из Google Fonts; без сети используются Georgia и Arial. Отдельные референсы кнопки и листа в исходной папке отсутствовали: их оформление создано по текстовому описанию.

Звук вступления: backg/fon2.mp3 запускается вместе с видео по нажатию на перо и плавно затихает за последние 2,5 секунды аудиодорожки. Звук не зацикливается; оставшаяся часть видео проходит в тишине. При повторном запуске звук начинается заново.
